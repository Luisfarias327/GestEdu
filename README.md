## Objetivo do software

O GestEdu é um sistema desktop de gestão educacional desenvolvido como parte do Projeto Integrador do curso Técnico em Desenvolvimento de Sistemas do SENAC. Seu objetivo é organizar e facilitar o gerenciamento de informações acadêmicas de uma instituição de ensino, centralizando dados de alunos, responsáveis, professores, disciplinas, turmas e notas.

## Funcionalidades e requisitos

- Cadastro e gerenciamento de alunos.
- Cadastro e gerenciamento de responsáveis.
- Cadastro e gerenciamento de professores.
- Cadastro e consulta de disciplinas.
- Organização de turmas e séries.
- Registro e consulta de notas trimestrais.
- Armazenamento de informações acadêmicas em banco de dados.
- Conexão da aplicação Java com o banco de dados MySQL.

As funcionalidades descritas representam os objetivos do sistema e podem estar sujeitas a alterações durante o desenvolvimento.

## Estrutura do repositório

- `src/` — código-fonte da aplicação Java.
- `pom.xml` — configuração do projeto Maven.
- `sql/` — scripts SQL do banco de dados.
- `docs/` — documentação do projeto.
- `java/` — arquivos Java mantidos nas etapas anteriores.

## Versionamento

O projeto utiliza Git para controlar as alterações do código-fonte e GitHub para armazenar o repositório remoto. Os commits registram as mudanças realizadas durante o desenvolvimento.
